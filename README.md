# Modbus RTU 数据转换工具 V3.0

一款功能强大的 Modbus RTU 数据转换工具，支持 IEEE 754 浮点数转换、串口通信和批量数据处理。

## 功能特性

### 数据转换
- **多种数据类型支持**
  - 32位浮点数 (float32)
  - 64位浮点数 (float64)
  - 16位有符号整数 (int16)
  - 16位无符号整数 (uint16)
  - 32位有符号整数 (int32)
  - 32位无符号整数 (uint32)

- **四种字节序规则**
  - 规则1 (B A D C): 部分国产设备
  - 规则2 (C D A B): 西门子/施耐德（推荐）
  - 规则3 (A B C D): 三菱/欧姆龙
  - 规则4 (D C B A): 极少使用

- **CRC-16 校验**: 自动计算并验证 Modbus CRC

### 串口通信
- 自动检测可用串口
- 支持常用波特率 (1200-115200)
- 支持校验位设置 (无/奇/偶)
- 实时数据收发
- 接收数据可直接转换

### 批量处理
- 支持导入 TXT/CSV 文件
- 多线程批量转换
- 进度显示
- 结果导出为 CSV

### 其他特性
- 多语言支持 (中文/English)
- 明暗主题切换
- 历史记录保存
- 快捷键支持

```bash

```

## 使用说明

### 数据转换
1. 在输入框中输入 Modbus RTU 十六进制报文
2. 选择合适的字节序规则和数据类型
3. 点击"单条转换"或按 `Ctrl+Enter`

**示例输入**: `02 03 04 05 1F 42 C9 08 CF`

### 串口通信
1. 选择串口和通信参数
2. 点击"连接"建立连接
3. 在发送框输入十六进制数据发送
4. 选中接收数据后点击"转换选中"

### 批量处理
1. 点击"导入"选择报文文件（每行一条报文）
2. 设置转换参数
3. 点击"批量转换"
4. 完成后点击"导出"保存结果

## 字节序说明

Modbus 协议中，浮点数由 4 个字节组成，不同厂商设备的字节排列顺序可能不同：

| 字节序 | 排列方式 | 常见设备 |
|--------|----------|----------|
| 规则1 | B A D C | 部分国产设备 |
| 规则2 | C D A B | 西门子、施耐德 |
| 规则3 | A B C D | 三菱、欧姆龙 |
| 规则4 | D C B A | 极少使用 |

> 如果转换结果不正确，请尝试切换不同的字节序规则。
