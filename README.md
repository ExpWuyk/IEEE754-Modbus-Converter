# Modbus RTU 数据转换工具 V4.0

一款功能强大的 Modbus RTU 数据转换工具，支持 IEEE 754 浮点数转换、串口通信和批量数据处理。采用现代化深色主题界面。

## 功能特性

### 数据转换
- **多种数据类型支持**
  - 32位浮点数 (Float32)
  - 64位浮点数 (Float64)
  - 16位有符号整数 (Int16)
  - 16位无符号整数 (UInt16)
  - 32位有符号整数 (Int32)
  - 32位无符号整数 (UInt32)

- **四种字节序规则**
  - BADC (规则1): 部分国产设备
  - CDAB (规则2): 西门子/施耐德（推荐）
  - ABCD (规则3): 三菱/欧姆龙
  - DCBA (规则4): 极少使用

- **CRC-16 校验**: 自动计算并验证 Modbus CRC

### 串口通信
- 自动检测可用串口
- 支持常用波特率 (9600-115200)
- 支持校验位设置 (无/奇/偶)
- 可折叠配置面板
- 实时数据收发
- 接收数据可直接转换

### 批量处理
- 支持导入 TXT/CSV 文件
- 多线程批量转换
- 实时进度条显示
- 结果导出为 CSV
- 状态颜色标识

### 界面特性
- **VS Code 风格深色主题**
- 卡片式布局设计
- 可折叠面板
- 响应式布局
- 快捷键支持

## 安装

- Python 3.10+

```bash

```

```bash
python main.py
```

### 打包为可执行文件
```bash
pyinstaller build.spec
```

## 使用说明

### 数据转换
1. 在输入框中输入 Modbus RTU 十六进制报文
2. 选择合适的字节序规则和数据类型
3. 点击「转换 (F5)」或按 `F5`

**示例输入**: `02 03 04 05 1F 42 C9 08 CF`

### 串口通信
1. 展开配置面板，选择串口和通信参数
2. 点击「连接」建立连接（配置面板自动折叠）
3. 在发送框输入十六进制数据发送
4. 选中接收数据后点击「转换选中」

### 批量处理
1. 点击「导入文件」选择报文文件（每行一条报文）
2. 设置数据类型和字节序
3. 点击「开始转换」
4. 完成后点击「导出结果」保存

## 字节序说明

Modbus 协议中，浮点数由 4 个字节组成，不同厂商设备的字节排列顺序可能不同：

| 字节序 | 排列方式 | 常见设备 |
|--------|----------|----------|
| BADC | B A D C | 部分国产设备 |
| CDAB | C D A B | 西门子、施耐德 |
| ABCD | A B C D | 三菱、欧姆龙 |
| DCBA | D C B A | 极少使用 |

> 如果转换结果不正确，请尝试切换不同的字节序规则。
